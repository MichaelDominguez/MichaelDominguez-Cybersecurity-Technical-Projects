# Security & Privacy Notice

This repository is a cybersecurity portfolio built from controlled labs, authorized coursework, and personal practice environments. The purpose is to demonstrate tool usage, technical writing, security reasoning, and hands-on project documentation.

## Scope of Included Evidence

The screenshots in this repository are included as watermarked evidence of hands-on work. They are preserved as submitted so reviewers can verify that the reports are connected to real command output, packet captures, AWS console actions, John the Ripper testing, and Kali Linux terminal activity.

No instructions in this repository should be used to scan, test, crack, or access systems without permission. The tools and workflows shown here are intended for defensive learning, controlled lab work, and professional review.

## Sensitive Information Handling

The markdown reports avoid publishing unnecessary live credentials, access keys, authentication tokens, or private account secrets. Credential-security material is described in a way that explains the method and defensive lesson without turning recovered passwords into the main focus of the portfolio.

## Authorized-Use Statement

Scanning, enumeration, password auditing, vulnerability review, and cloud-security configuration should only be performed on systems owned by the tester or systems where explicit authorization has been granted.
